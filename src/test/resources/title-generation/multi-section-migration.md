# migration-notes

## 总结

这部分不是简单结论，而是汇总接口契约、路由切换与上游改造边界。
迁移期间上游只允许切换调用地址，不允许擅自修改 path、请求参数和响应参数。
同时需要登记灰度范围、回退条件与负责人，避免迁移边界在执行中失真。

### 接口契约

- path 保持一致
- 请求参数保持一致
- 响应参数保持一致

### 路由切换

- 仅允许切换调用地址
- 不允许引入新入口

### 回退条件

- 明确回退触发条件
- 明确负责人和验收口径

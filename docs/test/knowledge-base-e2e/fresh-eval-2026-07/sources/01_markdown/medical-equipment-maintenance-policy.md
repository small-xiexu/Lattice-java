# 医疗设备维护管理总则

## 一、适用范围

本总则适用于全院所有纳入固定资产管理的医疗设备，包括但不限于：影像诊断设备、检验分析设备、手术室设备、ICU 监护设备、血液透析设备。

## 二、维护周期与内容

| 维护级别 | 周期 | 检查内容 | 责任人 |
|---------|------|---------|--------|
| 日检 | 每日 | 设备外观、运行指示灯、基础功能测试 | 设备操作员 |
| 周检 | 每周 | 关键部件状态、清洁、易损件检查 | 设备操作员 |
| 月检 | 每月 | 精度校准、安全保护装置测试、易损件更换 | 责任工程师 |
| 季检 | 每季度 | 全面性能测试、关键部件深度保养 | 责任工程师 + 厂商 |
| 年检 | 每年 | 全面检修、计量校准、安全评估 | 厂商 |

## 三、故障等级定义

| 等级 | 判定标准 | 响应时限 | 解决时限 | 是否需要停机 |
|-----|---------|---------|---------|:---:|
| P0 紧急 | 直接影响患者生命安全或导致设备无法运行 | < 15 分钟 | < 2 小时 | 是 |
| P1 高 | 影响核心诊断/治疗业务，但可切换备用设备 | < 1 小时 | < 8 小时 | 否 |
| P2 中 | 影响非核心功能或单台设备，不影响整体业务 | < 4 小时 | < 24 小时 | 否 |
| P3 低 | 仅影响辅助功能或外观问题，不影响使用 | < 24 小时 | < 72 小时 | 否 |

## 四、故障响应流程

1. **上报**：设备操作员通过工单系统或电话上报故障，描述现象并标注故障等级。
2. **分级**：责任工程师 15 分钟内确认故障等级，P0/P1 立即通知设备科负责人。
3. **派工**：根据故障等级和设备类型，指派责任工程师或联系外部厂商。
4. **处理**：工程师/厂商到场检修，记录处理过程、更换备件。
5. **验收**：处理完成后，设备操作员验收并签字确认。工单状态从"已解决"变更为"已验收"。

## 五、角色与职责

| 角色 | 职责 |
|------|------|
| 设备科负责人 | 统筹全院设备管理，审批设备采购与报废，P0/P1 故障升级决策 |
| 责任工程师 | 负责指定设备的日常维护、故障诊断与修复、巡检执行 |
| 设备操作员 | 设备日常使用、日检/周检执行、故障上报 |
| 外部厂商 | 按合同提供保修期内/外的维修服务、年检和计量校准 |

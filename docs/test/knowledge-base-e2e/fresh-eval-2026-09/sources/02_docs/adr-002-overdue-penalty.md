# ADR-002: 逾期扣分与阶梯罚金方案

## 背景
需要建立逾期归还的约束机制，包括信用分扣减和罚金计算。

## 决策
采用**阶梯式扣分 + 阶梯式罚金**方案：

### 信用分扣减
| 逾期天数 | 扣分 |
|---------|------|
| 1-7 天 | 2 分 |
| 8-14 天 | 5 分 |
| 15 天以上 | 10 分 |

### 阶梯罚金
| 逾期天数 | 罚金（元/天） |
|---------|-------------|
| 1-7 天 | 1.0 |
| 8-14 天 | 2.0 |
| 15 天以上 | 5.0 |

### 恢复机制
- 用户连续 30 天无逾期记录，恢复 3 分信用分

## 考虑因素
- 阶梯方案对短期逾期更宽容，对长期逾期惩罚更严厉
- 信用分初始值 100，低于 60 分限制借书权限

## 影响
- `CreditServiceImpl` 中的扣分逻辑和恢复逻辑
- `FineServiceImpl` 中的罚金计算逻辑
- `application.yml` 中的 `library.credit.*` 和 `library.fine.*` 配置项

# 供应链来料质量管理总则

## 一、适用范围

本总则适用于所有进入生产环节的原材料、外购零部件和外包半成品的来料质量管理。所有供应商须遵守本制度规定的检验标准和流程。

## 二、来料检验流程

1. **到货登记**：仓库管理员在 ERP 系统中登记到货物料，生成报检单。
2. **报检通知**：系统自动通知质检员进行来料检验。
3. **抽样**：质检员根据物料类别和 AQL 标准确定抽样方案。一般检验水平 II 级，特殊物料按水平 III 级执行。
4. **检验**：按照对应检验指导书执行尺寸、外观、性能、材质检测，记录检验数据。
5. **判定**：质检主管根据 AQL 标准和检验结果做出合格/不合格判定。
6. **入库/隔离**：合格物料办理入库；不合格物料移至不合格品隔离区，启动不合格品处理流程。

## 三、供应商评级标准

| 等级 | 质量评分 | 交付评分 | 响应评分 | 综合评级 | 检验频率 |
|:---:|:---:|:---:|:---:|------|------|
| A | >= 90 | >= 85 | >= 90 | 优秀 | 每 5 批抽检 1 批 |
| B | >= 80 | >= 75 | >= 80 | 良好 | 每 3 批抽检 1 批 |
| C | >= 70 | >= 65 | >= 70 | 合格 | 每批抽检 |
| D | < 70 | < 65 | < 70 | 待改善 | 每批全检 + 暂停新订单 |

供应商评级每季度复评一次。连续两个季度为 D 级的供应商，取消合格供应商资格。

## 四、不合格品分级

| 缺陷等级 | 定义 | 示例 | 处理方式 | 审批层级 |
|---------|------|------|---------|---------|
| 严重缺陷 | 影响产品安全、功能或法规合规 | 尺寸超差导致装配失效、材质不符、安全件破损 | 整批退货 + CAPA | 质量经理 |
| 主要缺陷 | 超出规格但可通过返工修复 | 表面划痕、色差、标识不清 | 退货或让步接收 + 供应商整改 | 质检主管 |
| 次要缺陷 | 不影响使用功能的外观或包装瑕疵 | 轻微磕碰、标签偏移 | 让步接收或返工 | 质检员 |

## 五、批次追溯要求

- 所有来料须按"LOT-YYMMDD-序号"格式编制批次号。
- 批次号从来料检验到成品出库全链路可追溯。
- 检验记录和批次追踪记录的保存期限为 **5 年**。
- 发生质量问题时，须在 **4 小时**内完成问题批次的追溯定位。

## 六、角色与职责

| 角色 | 职责 |
|------|------|
| 质检员 | 执行来料抽样和检验，记录检验数据，标识不合格品 |
| 质检主管 | 审核检验报告，做出合格/不合格判定，审批让步接收 |
| 采购经理 | 协调供应商反馈，跟进不合格品处理，参与供应商评级 |
| 仓库管理员 | 到货登记，合格品入库，不合格品隔离管理 |

# 校园实验室安全管理手册

文档编号：LAB-SAFETY-2026-05

适用范围：本手册适用于校园教学实验室、开放共享实验平台和由学院统一管理的学生创新实验空间。手册用于说明实验室安全管理、人员职责、化学品存储、应急设备维护和日常检查要求。

## 化学品分类存储

化学品按危险性、反应活性、挥发性和日常使用频率划分为 A、B、C、D 四个危险等级。本节也可概括为“实验室化学品分级存储管理规范”。

A 级化学品包括强腐蚀、高挥发、强氧化、易燃易爆或对人员健康有严重危害的试剂。A 级化学品必须存放在专用安全柜内，按性质选择防腐蚀柜、防爆冰箱或双人双锁柜，领用与归还均需登记。

B 级化学品包括常见易燃、有腐蚀性、对环境有一定危害或需隔离存放的试剂。B 级化学品应存放在通风橱、防火柜、防潮柜或密封容器内，并由指定人员定期核对库存。

C 级化学品为低危险但仍需远离热源、火源或不相容物质的普通试剂。C 级化学品可存放在普通试剂柜内，但必须保持标签清晰、容器完好。

D 级化学品为常规教学试剂或低风险盐类材料，可存放在普通试剂架或普通试剂柜中。D 级化学品仍需纳入台账，不得与食品、饮品或个人物品混放。

不同类别试剂不得仅按名称字母顺序混放。酸类、碱类、氧化剂、还原剂、易燃液体和强挥发性试剂应分区、分柜、分层管理。发现包装破损、标签缺失、结晶析出或异常气味时，应暂停使用并报告实验室安全员。

## 紧急洗眼冲淋设备

每个涉及腐蚀性、刺激性或挥发性化学品的实验室区域，应在人员可快速到达的位置设置紧急洗眼冲淋设备。设备通道不得堆放箱体、仪器或个人物品，地面应保持防滑和无遮挡。

使用紧急洗眼设备时，应立即开启水流，持续冲洗受污染眼部至少 15 分钟，并尽快通知实验指导教师和实验室安全员。使用紧急冲淋设备时，应迅速脱离污染源，脱去被污染的外层衣物，持续冲淋并等待进一步医疗处理。

洗眼冲淋设备由实验室安全员组织检查。日常目视检查每日一次，确认通道畅通和标识清晰；功能测试每周一次，确认水流稳定；全面维护每月一次，记录水压、喷头状态和排水情况。

## 废弃试剂处置

废弃试剂必须分类收集，不得倒入水槽、生活垃圾桶或普通废液桶。酸性废液、碱性废液、有机溶剂、含重金属废液、含卤有机废液和固体污染物应分别使用带标签的专用容器收集。

废弃试剂容器标签应包含废弃物类别、主要成分、产生实验、产生日期、责任人和危险提示。混合废液前必须确认相容性，禁止将强氧化剂与有机溶剂混合，禁止将酸性废液与含氰或含硫化物废液混合。

废弃试剂移交前，由实验指导教师确认来源和类别，由实验室安全员核对标签与数量，并由设备管理员协助安排临时存放区域。移交校级危废管理单位时，应保留移交记录、称量记录和接收回执。

## 实验室准入制度

实验室人员分为课程学生、项目学生、研究助理、实验指导教师、设备管理员和访客。课程学生和项目学生进入实验室前必须完成安全培训、准入测评和实验项目风险告知。未通过准入测评的人员不得独立进入实验室。

门禁权限按实验需求和人员身份分级授予。课程学生仅在课程时段进入指定实验区域；项目学生可在授权时段进入项目实验区；访客必须由实验室人员陪同，不得独立操作设备或接触化学品。

准入资格不是永久授权。出现违规操作、未按要求记录、擅自带入外来试剂或未及时报告险情的人员，应暂停门禁权限并重新培训。

## 安全检查周期

实验室安全检查分为日检、周检、月检和季检。

日检由当日使用人员和实验指导教师共同完成，重点检查水电气关闭状态、台面整洁、废液桶容量、门窗关闭和明火隐患。

周检由实验室安全员组织，重点检查化学品柜、洗眼冲淋设备、消防通道、安全标识和个人防护用品补充情况。

月检由实验室安全员和设备管理员联合完成，重点检查设备台账、维护记录、特种设备状态、危废暂存区域和借用归还记录。

季检由实验室主任组织，覆盖实验室制度执行、人员准入记录、应急演练记录、整改闭环和高风险实验审批情况。

检查发现的问题应登记为隐患项，明确责任人、整改期限和复查人。未完成整改的隐患不得在检查记录中关闭。

## 人员职责定义

实验室安全员负责安全制度执行、安全检查、隐患排查、应急演练组织、危险化学品台账核对和安全培训记录维护。安全员重点关注人员行为、化学品风险、现场环境和应急准备。

设备管理员负责设备台账、借用审批、维护保养安排、设备状态标识、维修记录归档和大型设备使用预约管理。设备管理员重点关注设备可用性、借用合规性和维护计划执行。

实验指导教师负责实验教学风险告知、学生操作指导、实验前安全交底、实验过程监督、废弃试剂来源确认和学生准入资格核验。实验指导教师重点关注教学过程中的操作风险和学生行为规范。

实验室主任负责制度批准、资源协调、重大隐患整改督办、高风险实验审批和跨部门应急协调。实验室主任不替代安全员或设备管理员的日常记录职责，但对实验室整体安全管理结果负责。

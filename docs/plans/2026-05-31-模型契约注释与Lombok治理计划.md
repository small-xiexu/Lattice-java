# 模型契约注释与 Lombok 治理计划

更新时间：2026-05-31
状态：二审 PASS，已按非阻塞建议微调，作为后续唯一推进台账

本计划覆盖 API DTO、内部 domain model、entity-like model、配置类与 graph/state 类的字段契约注释、Lombok 使用和构造入口治理。本文档已通过 agentB 第二轮只读审查，后续按批次推进时以本文档作为唯一进度台账，每完成一批必须回写状态、验证结果和残留风险。

## 当前结论

- 候选规模：API 边界类约 99 个，domain/model/config 类约 85 个，去重后约 182 个候选文件；另有 `query/service` 3 个核心 DTO、`graph/state` 6 个状态类和 `infra/persistence/*Record.java` 43 个记录类需要明确边界。
- 目标不是机械补字段翻译，而是按层补齐工程契约：API 写调用契约，domain 写领域语义，entity-like model 写持久化/生命周期语义，config 写运行配置语义。
- 不做全局一把梭。每轮限定 5-10 个类或一个小模块，优先低风险 API DTO，再处理 domain/config，最后治理实体与 graph/state 类。
- `@Data` 不作为默认选项。API DTO 优先 `@Getter` + 稳定 Jackson 入口；domain/config/entity-like 类按框架约束保守处理。
- 已完成试点：`QueryResponse` 已提交 `2888796`；`QuerySourceResponse` / `QueryArticleResponse` 已提交 `b38acdc`。

## 注释标准

| 类别 | 字段注释要回答的问题 | 不要写 |
|---|---|---|
| API Request/Response | 调用方如何读取；为空代表什么；影响前端、缓存、审计、引用或错误处理的哪个行为 | 字段名翻译、接口说明重复、无运行语义的中文释义 |
| Domain Model / Value Object | 表达哪个领域概念；生命周期在哪个阶段产生；核心不变量是什么；被哪些服务消费 | 仅解释 Java 类型、重复 getter 名称 |
| Entity-like / 持久化模型 | 与数据库字段、索引、状态机、审计时间、生命周期、可空性的关系 | 暗示未实现的数据迁移或兼容承诺 |
| Config / Properties | 配置前缀、默认值、开关影响、fail-open/fail-closed 语义、变更后影响的链路 | 只写“是否启用”“超时时间”这类字段翻译 |
| Graph/State/WorkingSet | 节点间传递的运行态含义；谁写入、谁读取；失败重试时是否可复用 | 把临时变量包装成业务概念 |
| Enum | 每个枚举值驱动的行为差异、状态流转或外部协议含义 | 只翻译枚举名 |

## Lombok 与构造入口规则

| 场景 | 推荐 | 禁止/谨慎 |
|---|---|---|
| 不可变 API Response | `@Getter`、唯一 `@JsonCreator`、必要时 `@Builder` | `@Data`、无约束 `@Setter`、多个等价构造器 |
| API Request / Spring binding | 保留框架需要的无参构造/Setter；字段注释解释输入约束 | 为了统一强改成不可变导致绑定失败 |
| Controller 内部敏感 DTO | 若包含 `apiKey`、`token`、`password` 等敏感字段，优先改用 `@Getter`/`@Setter`，或对敏感字段使用 `@ToString.Exclude` | 保留 `@Data` 且允许 `toString()` 输出密钥、令牌或凭证 |
| Domain Value Object | 优先显式构造器或 factory，注释写不变量 | 默认加 `@Data` 暴露可变性 |
| JPA/Entity-like model | 保留框架需要的 no-arg；`equals/hashCode/toString` 谨慎 | `@Data`、关系字段参与 `toString`、对实体盲加 `@Builder` |
| Config Properties | 保持当前 Spring Boot 绑定方式；注释写配置语义 | 改绑定风格但不覆盖启动验证 |
| Graph/State 类 | 若确需可变，明确“运行态容器”语义 | 为了去 `@Data` 大范围改 graph 节点调用 |

## 每轮执行模板

1. 读取本文档，确认本轮批次状态。
2. 将本轮批次状态改为 `进行中`，备注允许修改范围。
3. 只修改本批次文件及必要的最小调用点/测试适配。
4. 完成后运行本批次定向测试；涉及公共 API 或构造器收敛时运行 redline。
5. 回写本文档：状态、实际修改文件、验证结果、残留风险。
6. 输出本轮 `*_fix_result_report.md`。
7. 未经用户明确要求，不 stage、不 commit、不 push。

## 每轮验收门槛

| 变更类型 | 最低验证 | 升级验证 |
|---|---|---|
| 仅字段 Javadoc | 编译相关定向测试可选；至少 `rg` 自查无空泛模板 | 每 3-4 批跑一次 `mvn test` |
| Lombok 注解调整 | 受影响定向测试 + 编译 | 若构造器/Jackson 变化，补序列化/反序列化测试 |
| 构造器收敛 | 搜索直接 `new Xxx(...)` 残留 + 定向测试 | 涉及 API 响应时跑 controller/service 相关测试 |
| Config properties | Spring context / 配置绑定测试 | 涉及 fail-closed/fail-open 时补运行路径验证 |
| Entity-like model | 持久化/mapper/repository 定向测试 | 涉及 equals/hashCode/toString 时全量测试 |

## 风险与禁令

- 禁止用字段名翻译冒充契约注释。
- 禁止为了统一把所有类改成 `@Data` 或全部改成 `@Builder`。
- 禁止在 query/retrieval/answer/fallback 主链里夹带行为修复。
- 禁止修改 `docs/模型绑定配置参考.md`、`special_cases_report.md`、redline allowlist。
- 禁止一轮同时处理 API DTO、domain、config、entity 多种风险类别。
- JPA/entity-like 类必须先确认框架约束；没有验证前不改构造器、`equals/hashCode`、`toString`。
- Spring `@ConfigurationProperties` 类必须保持当前绑定方式，除非单独做配置绑定迁移方案。

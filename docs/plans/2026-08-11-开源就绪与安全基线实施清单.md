## 目标

补齐公开仓库最基本的维护、安全与持续集成入口，让外部贡献者能够理解项目边界、复现门禁并负责任地报告漏洞。本清单是本轮唯一进度台账。

## 范围边界

- 本轮只修改文档、根目录 `LICENSE`、`pom.xml` 的公开项目与许可证元数据、`.github/**` 仓库治理配置和 `.codex/maven-settings.xml` 的路径可移植性。
- 不修改 `src/main/**`、`src/test/**`、`frontend/src/**`、脚本或运行配置。
- 不调用真实模型、不清理主库、不重建索引、不启动额外容器。为全量测试只重建独立的 `ai-rag-knowledge-test.lattice`，并临时启动既有 `redis` 容器；验证后 Redis 已恢复为原先的停止状态。
- 不合并现有机器人 PR。维护者已于 2026-08-12 明确授权提交本轮开源基线改动、直接推送 `main` 并验证 GitHub CI 与仓库设置；`docs/LLM-Wiki知识库完善技术方案.md` 明确排除。
- 维护者已于 2026-08-12 确认采用 `Apache-2.0`；仅添加官方标准文本和许可证元数据，不代填未经确认的版权主体。

## 后续安全债务

以下事项涉及生产代码或部署决策，不纳入本轮文档/治理改动；后续应按“一轮一个根因”单独实施和验证：

1. 删除默认 API Key，并增加密钥配置与日志泄露测试。
2. 为管理 API、MCP 和高风险维护操作建立认证、授权与最小权限模型。
3. 对编译目录、Vault、快照和 manifest 路径实施允许根目录、符号链接与删除目标约束。
4. 对 Git/远程资料源增加协议、主机、重定向、内网地址和凭据传递限制。

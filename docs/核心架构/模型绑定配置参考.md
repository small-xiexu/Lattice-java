# 模型绑定配置参考

## 1. 一句话结论

当前项目跑通 compile、query、deep_research 三条主链，需要配置 **2 个连接 + 2 个模型 + 10 条绑定**。全部通过 `/admin/settings` 页面或 Admin API 完成，不用改配置文件。

共享一个 Chat 模型给多个角色时，**不要在模型 profile 上填写 `timeoutSeconds`**。否则命中这个 profile 的 writer / reviewer / fixer / query / deep_research 角色都会被统一成同一个超时。

---

## 2. 配置顺序

必须按顺序：**先建连接 → 再建模型 → 最后建绑定**。模型依赖连接 ID，绑定依赖模型 ID。

如果你要复用同一个 Chat 模型给 10 条绑定，推荐做法是：

- Chat 模型的 `timeoutSeconds` 留空
- 让 compile 的 writer / reviewer / fixer 回退到服务端角色超时配置
- 只有在你明确接受“所有命中该模型的角色共用一个超时”时，才在模型 profile 上填写 `timeoutSeconds`

---

## 4. 模型配置（2 个）

| 字段 | 值 | 说明 |
| --- | --- | --- |
| modelCode | `gpt-5.5` | |
| connectionId | **Chat 连接的 ID** | 从上一步返回值取 |
| modelName | `gpt-5.5` | 传给网关的 model 名 |
| modelKind | `chat` | |
| temperature | 0.1 | |
| maxTokens | 4096 | |
| timeoutSeconds | 留空 | 共享 profile 时不要填写；否则所有命中该 profile 的角色都会统一使用同一个超时 |
| enabled | true | |

```bash
curl -s -X POST http://127.0.0.1:18082/api/v1/admin/llm/models \
  -H 'Content-Type: application/json' \
  -d '{
    "modelCode": "gpt-5.5",
    "connectionId": <CHAT_CONNECTION_ID>,
    "modelName": "gpt-5.5",
    "modelKind": "chat",
    "temperature": 0.1,
    "maxTokens": 4096,
    "enabled": true
  }'
```

当前仓库的 compile 角色默认超时为：

- writer: 180 秒
- reviewer: 120 秒
- fixer: 180 秒

这些默认值只在 **模型 profile 没有填写 `timeoutSeconds`** 时生效。

## 5. Agent 绑定配置（10 条）

三场景角色映射（代码写死在 `AdminLlmConfigController.createSceneRoleOptions()`）：

| Scene | 角色 | 说明 |
| --- | --- | --- |
| `compile` | writer, reviewer, fixer | 知识编译管线 |
| `query` | answer, reviewer, rewrite | 查询回答管线 |
| `deep_research` | planner, researcher, synthesizer, reviewer | 深度研究管线 |

**所有 10 条绑定的 `primaryModelProfileId` 都指向同一个 Chat 模型（gpt-5.5 的 ID）。**

这套共享绑定只有一个前提：**Chat 模型 profile 的 `timeoutSeconds` 留空**。如果你把它填成 `120`，那 compile.writer / compile.reviewer / compile.fixer 也都会一起变成 `120`。

### 5.1 Compile 场景（3 条）

```bash
CHAT_MODEL_ID=<gpt-5.5模型ID>

for role in writer reviewer fixer; do
  curl -s -X POST http://127.0.0.1:18082/api/v1/admin/llm/bindings \
    -H 'Content-Type: application/json' \
    -d "{
      \"scene\": \"compile\",
      \"agentRole\": \"$role\",
      \"primaryModelProfileId\": $CHAT_MODEL_ID,
      \"enabled\": true
    }"
done
```

### 5.2 Query 场景（3 条）

```bash
for role in answer reviewer rewrite; do
  curl -s -X POST http://127.0.0.1:18082/api/v1/admin/llm/bindings \
    -H 'Content-Type: application/json' \
    -d "{
      \"scene\": \"query\",
      \"agentRole\": \"$role\",
      \"primaryModelProfileId\": $CHAT_MODEL_ID,
      \"enabled\": true
    }"
done
```

### 5.3 Deep Research 场景（4 条）

```bash
for role in planner researcher synthesizer reviewer; do
  curl -s -X POST http://127.0.0.1:18082/api/v1/admin/llm/bindings \
    -H 'Content-Type: application/json' \
    -d "{
      \"scene\": \"deep_research\",
      \"agentRole\": \"$role\",
      \"primaryModelProfileId\": $CHAT_MODEL_ID,
      \"enabled\": true
    }"
done
```

## 7. 一键配置脚本

把上面的步骤合并成一条脚本。先启动应用，然后执行：

```bash
#!/bin/bash
BASE=http://127.0.0.1:18082/api/v1/admin/llm
VECTOR_BASE=http://127.0.0.1:18082/api/v1/admin/vector

echo "=== Step 1: 创建 Chat 连接 ==="
CHAT_CONN=$(curl -s -X POST $BASE/connections \
  -H 'Content-Type: application/json' \
  -d '{
    "connectionCode": "local_openai",
    "providerType": "openai_compatible",
    "baseUrl": "http://127.0.0.1:8888",
    "apiKey": "<your-openai-api-key>",
    "enabled": true
  }')
echo "$CHAT_CONN"
CHAT_CONN_ID=$(echo "$CHAT_CONN" | jq -r '.id')

echo "=== Step 2: 创建 Embedding 连接 ==="
EMBED_CONN=$(curl -s -X POST $BASE/connections \
  -H 'Content-Type: application/json' \
  -d '{
    "connectionCode": "zhipu_embedding",
    "providerType": "openai_compatible",
    "baseUrl": "https://open.bigmodel.cn/api/paas/v4",
    "apiKey": "<your-zhipu-api-key>",
    "enabled": true
  }')
echo "$EMBED_CONN"
EMBED_CONN_ID=$(echo "$EMBED_CONN" | jq -r '.id')

echo "=== Step 3: 创建 Chat 模型 ==="
CHAT_MODEL=$(curl -s -X POST $BASE/models \
  -H 'Content-Type: application/json' \
  -d "{
    \"modelCode\": \"gpt-5.5\",
    \"connectionId\": $CHAT_CONN_ID,
    \"modelName\": \"gpt-5.5\",
    \"modelKind\": \"chat\",
    \"temperature\": 0.1,
    \"maxTokens\": 4096,
    \"enabled\": true
  }")
echo "$CHAT_MODEL"
CHAT_MODEL_ID=$(echo "$CHAT_MODEL" | jq -r '.id')

echo "=== Step 4: 创建 Embedding 模型 ==="
EMBED_MODEL=$(curl -s -X POST $BASE/models \
  -H 'Content-Type: application/json' \
  -d "{
    \"modelCode\": \"embedding-3\",
    \"connectionId\": $EMBED_CONN_ID,
    \"modelName\": \"embedding-3\",
    \"modelKind\": \"embedding\",
    \"expectedDimensions\": 2000,
    \"supportsDimensionOverride\": true,
    \"enabled\": true
  }")
echo "$EMBED_MODEL"
EMBED_MODEL_ID=$(echo "$EMBED_MODEL" | jq -r '.id')

echo "=== Step 5: 创建 10 条 Agent 绑定 ==="
for scene_role in "compile:writer" "compile:reviewer" "compile:fixer" \
                  "query:answer" "query:reviewer" "query:rewrite" \
                  "deep_research:planner" "deep_research:researcher" \
                  "deep_research:synthesizer" "deep_research:reviewer"; do
  scene="${scene_role%%:*}"
  role="${scene_role##*:}"
  curl -s -X POST $BASE/bindings \
    -H 'Content-Type: application/json' \
    -d "{
      \"scene\": \"$scene\",
      \"agentRole\": \"$role\",
      \"primaryModelProfileId\": $CHAT_MODEL_ID,
      \"enabled\": true
    }" > /dev/null
  echo "  binding: $scene / $role -> gpt-5.5 ($CHAT_MODEL_ID)"
done

echo "=== Step 6: 配置向量模型 ==="
curl -s -X PUT $VECTOR_BASE/config \
  -H 'Content-Type: application/json' \
  -d "{
    \"vectorEnabled\": true,
    \"embeddingModelProfileId\": $EMBED_MODEL_ID
  }"
echo ""

echo "=== 配置完成 ==="
echo "Chat 连接 ID:     $CHAT_CONN_ID"
echo "Embedding 连接 ID: $EMBED_CONN_ID"
echo "Chat 模型 ID:     $CHAT_MODEL_ID"
echo "Embedding 模型 ID: $EMBED_MODEL_ID"
```

## 8. 常见漏配/错配

| 问题 | 现象 | 原因 |
| --- | --- | --- |
| 缺 deep_research 绑定 | 启动期告警"deep_research 绑定未就绪"，Deep Research 调用 fail-closed | 只配了 compile + query（7 条），漏了 deep_research 的 4 条 |
| 共享 Chat 模型写了 `timeoutSeconds` | compile/query/deep_research 命中同一模型时全部共用一个超时；例如 writer/fixer 也被锁成 120 秒 | `timeoutSeconds` 是模型 profile 级别，不是角色级别 |
| 缺 embedding 连接/模型 | `/api/v1/admin/vector/config` PUT 失败或编译时向量写入报错 | 只建了 chat 连接+模型，忘了 embedding |
| embedding 模型没设 `expectedDimensions` | 向量维度默认 2048，与 pgvector 索引不匹配 | 当前基线是 2000 维，必须显式设 |
| binding 的 scene 写错大小写 | 校验失败 "agentRole与scene不匹配" | scene 必须全小写：`compile`/`query`/`deep_research` |
| agentRole 写错 | 同上 | compile: writer/reviewer/fixer；query: answer/reviewer/rewrite；deep_research: planner/researcher/synthesizer/reviewer |
| 向量配置的 `embeddingModelProfileId` 填了 chat 模型 ID | embedding 调用失败 | 必须填 embedding 模型的 ID，不是 chat 模型 ID |
| `supportsDimensionOverride` 没设 true | embedding 调用用默认 2048 维 | zhipu embedding-3 默认 2048，需要显式允许覆盖到 2000 |

如果你已经按旧版本文档把共享 Chat 模型配成了 `timeoutSeconds: 120`，重跑前先做一件事：

1. 在 `/admin/settings` 编辑 Chat 模型，把 `timeoutSeconds` 清空
2. 如果页面不支持清空，就删除这条 Chat 模型后按本文档重新创建
3. 重新发起 compile 任务，让新的 execution snapshot 重新生成

## 9. 验证配置是否完整

```bash
# 检查连接数
curl -s http://127.0.0.1:18082/api/v1/admin/llm/connections | jq '.count'
# 期望: 2

# 检查模型数
curl -s http://127.0.0.1:18082/api/v1/admin/llm/models | jq '.count'
# 期望: 2

# 检查绑定数
curl -s http://127.0.0.1:18082/api/v1/admin/llm/bindings | jq '.count'
# 期望: 10

# 检查每个 scene 的绑定是否齐全
curl -s http://127.0.0.1:18082/api/v1/admin/llm/bindings | jq '[.items[] | {scene, agentRole}] | group_by(.scene) | map({scene: .[0].scene, roles: map(.agentRole) | sort})'
# compile:         ["fixer","reviewer","writer"]
# query:           ["answer","reviewer","rewrite"]
# deep_research:   ["planner","researcher","reviewer","synthesizer"]

# 检查向量配置
curl -s http://127.0.0.1:18082/api/v1/admin/vector/config | jq '{vectorEnabled, embeddingModelProfileId}'
# vectorEnabled: true, embeddingModelProfileId 非 null
```
